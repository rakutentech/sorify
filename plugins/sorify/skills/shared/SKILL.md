# Shared Sorify references

Use this skill as supporting guidance for the `sorify-generate` workflow. Read
the specific reference file needed for the current phase:

- `explorer-instructions.md` for DOM and browser exploration
- `analyzer-instructions.md` for source-code condition analysis
- `designer-instructions.md` for turning conditions into test cases
- `generator-patterns.md` for DOM test generation
- `generator-patterns-mock.md` for network-mock test generation

These references describe the workflow and generated code. Use the MCP tools
provided by the current host rather than assuming Claude-specific tool-name
prefixes.
